# 📚 Gerenciador de Biblioteca

Uma aplicação web interativa desenvolvida em **Python** com **Streamlit** para gestão e organização de acervo bibliográfico.

## 🔐 Acesso Administrativo

Para aceder às funcionalidades de gestão do acervo (como adicionar ou alterar dados), utilize as credenciais padrão da aplicação:
- **Utilizador:** `admin`
- **Senha:** `admin123`

## 🚀 Funcionalidades

- **Autenticação de Administrador**: Acesso restrito para gestão de acervo e utilizadores.
- **Cadastro e Consulta de Livros**: Registo de novos títulos, autores e dados de publicação.
- **Controlo de Empréstimos**: Organização de livros emprestados e prazos de devolução.
- **Interface Intuitiva**: Painel visual prático construído com o ecossistema Streamlit.

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- **Streamlit**
